# Frequently Asked Questions (FAQ)

Common questions about the Hello World Project.

---

## 🚀 Getting Started

### Q: How do I get started with this project?
**A:** See [QUICK-START.md](QUICK-START.md) for a 2-minute setup guide.

### Q: Do I need to install anything?
**A:** No! This is a static HTML project with zero dependencies. Just open `index.html` in your browser.

### Q: How do I view the project?
**A:** 
1. Double-click `index.html`
2. Or drag-drop into browser
3. Or run a local server (see DEVELOPMENT.md)

### Q: Can I run this project offline?
**A:** Yes! All files are self-contained and work offline.

## 🌍 Multilingual Content

### Q: How many languages are supported?
**A:** 12 languages:
- English, Indonesian, Korean, Japanese
- Chinese, Spanish, French, German
- Italian, Russian, Vietnamese, Lao

### Q: How do I access multilingual versions?
**A:** Navigate to the `multilingual/` folder and open any `index-[language-code].html` file.

### Q: Can I add a new language?
**A:** Yes! See [CONTRIBUTING.md](CONTRIBUTING.md) for guidelines. We welcome new language contributions.

### Q: What's the language code for my language?
**A:** Use ISO 639-1 codes:
- English: `en`
- Spanish: `es`
- French: `fr`
- German: `de`
- Chinese: `zh`
- Japanese: `ja`
- See [HTML-TAG-DOCUMENTATION.md](multilingual/HTML-TAG-DOCUMENTATION.md)

### Q: Are all languages using UTF-8 encoding?
**A:** Yes! All files use UTF-8 encoding to support all languages and special characters.

## 👨‍💻 Development

### Q: How do I edit the project?
**A:** 
1. Open any `.html` or `.md` file in a text editor
2. Make changes
3. Save file
4. Refresh browser to see changes

### Q: What text editor should I use?
**A:** Any text editor works:
- VS Code (recommended)
- Sublime Text
- Notepad++
- Vim
- Even Notepad

### Q: Is VS Code required?
**A:** No, but recommended. It has useful extensions for web development.

### Q: How do I see changes in real-time?
**A:** Use VS Code Live Server extension or run a local server (see DEVELOPMENT.md).

### Q: Do I need to know how to code?
**A:** Basic HTML knowledge helps, but the code is well-commented and documented.

## 💾 Files & Encoding

### Q: Why UTF-8 encoding?
**A:** UTF-8 supports all languages and special characters. It's the web standard.

### Q: Can I use a different encoding?
**A:** Not recommended. UTF-8 is required for proper multilingual support.

### Q: Are files line-ending dependent?
**A:** No. LF (Linux) or CRLF (Windows) both work fine.
