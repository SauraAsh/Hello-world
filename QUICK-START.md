# Quick Start Guide

Get the Hello World project up and running in 2 minutes!

## ⚡ 30-Second Setup

### Option 1: Clone & Open
```bash
git clone git@github.com:SauraAsh/Hello-world.git
cd hello-world
open index.html
```

### Option 2: Direct Download
1. Download the repository as ZIP
2. Extract to your desired location
3. Open `index.html` in your browser

---

## 🌐 View the Application

1. **Using Browser:**
   - Double-click `index.html`
   - Or drag-drop into browser
   - Or right-click → Open with → Browser

2. **Using Local Server (Optional):**
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Python 2
   python -m SimpleHTTPServer 8000
   
   # Node.js (with http-server)
   npx http-server
   ```
   Then visit: `http://localhost:8000`

## 🛠 Development

### Prerequisites
- Text editor (VS Code, Sublime, etc.)
- Modern web browser
- Git (optional)

### No Build Process Needed!
This is a static HTML project with zero dependencies.

### Making Changes
1. Edit any `.html` file
2. Save the file
3. Refresh browser (Ctrl+R or Cmd+R)
4. Changes appear instantly
